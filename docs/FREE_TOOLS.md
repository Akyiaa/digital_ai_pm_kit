# Free-first tool choices

| Task | Free route | Optional paid route |
|---|---|---|
| SQL | SQLite included with Python; SQLBolt lessons | Hosted warehouse |
| Data analysis | Python csv/sqlite3; spreadsheet app | Paid BI |
| Prototypes | Figma free tier, sketches, static HTML | Paid design plan |
| AI prototype | Python rules baseline, optionally local Ollama model | Metered AI API |
| Evaluation | CSV test set + Python unittest | Paid evaluation platform |
| Dashboard | Python console summaries or local HTML | Cloud dashboard hosting |
| Portfolio | GitHub public repo and README | Custom domain |

**Important:** a rules-based classifier is NOT an LLM. For AI PM credibility, document an LLM experiment using a personally authorised tool or local model, with model identity, evaluation and cost; optional for the £0 core. Local models require enough RAM/disk.
