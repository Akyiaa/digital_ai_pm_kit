# Start here: portable workflow

**Minimum:** Python 3.10+, text editor, Git optional. No account, subscription, API key, cloud laptop required to run included samples.

- Open `docs/ROADMAP.md` for the week-by-week plan and URLs.
- Open `learning/week-XX/README.md` for a weekly checklist.
- Run `python projects/01-kbeauty-product/app.py` (similarly 02 and 03) from repository root.
- Use `python -m unittest discover -s tests` for smoke tests.
- Store proof in each project `artifacts/` folder: screenshots, charts, decisions, demo links.
- For Figma, the free plan is optional: paper sketches or local image exports also work.
- Budget: core £0; optional LLM API calls, hosting, paid Figma features and some courses may cost extra. Pricing/links can change; check providers.

**Suggested weekly rhythm:** 3h learning, 3h building, 1h documenting, 1h applications/review. Starting week 4, apply while learning.

**Definition of done:** runnable or clickable artifact; README with how to reproduce; real or synthetic evidence labelled; limitations; decision log; screenshot/demo; interview-ready explanation.
